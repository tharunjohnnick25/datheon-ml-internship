# Datheon Machine Learning Internship — Predictive Modeling Tasks

This repository contains three reproducible machine-learning notebooks built for Google Colab.

## Tasks

1. **Iris multi-class classification** — Logistic Regression vs Decision Tree. Reports accuracy, macro precision/recall/F1, classification reports, confusion matrices, and 2-feature decision-boundary illustrations.
2. **Housing price regression** — OLS vs tuned Ridge and Lasso. Includes missing-value imputation, categorical encoding, numeric interaction features, GridSearchCV, RMSE, MAE, R², actual-vs-predicted plots, and residual analysis.
3. **Telecom customer churn** — Random Forest vs XGBoost. Uses class weighting, one-hot encoding, ROC-AUC, F1, confusion matrices, ROC curves, 3-fold cross-validation, and feature importance plots.

## Run in Google Colab

1. Upload a notebook from `notebooks/` to [Google Colab](https://colab.research.google.com/).
2. Select **Runtime → Run all**.
3. Ensure the Colab runtime has internet access so the notebooks can download the public CSV datasets.
4. Task 3 installs XGBoost in its first cell.
5. The notebooks save metric CSVs and plots into an `outputs/` folder relative to the notebook's working directory. If you run notebooks from Colab's temporary session, download or commit the generated outputs after running.

## Installation (local environment)

```bash
pip install -r requirements.txt
```

Google Colab already includes most packages used in Tasks 1 and 2. Task 3 installs XGBoost inside the notebook if required.

## Evaluation and reproducibility

All notebooks use fixed random seeds and hold-out test sets. Preprocessing is fitted on training data. Housing model selection uses cross-validation within the training split. Churn cross-validation is performed on training data separately from the held-out test set.

**Do not report guessed metrics.** Run the notebooks and copy the actual results generated by your runtime into your internship submission and LinkedIn walkthrough. Performance depends on dataset version, package versions, split, and model configuration. The suggested churn ROC-AUC of 0.80 is a target, not a guarantee.
